**Critical (backend, `backend/pyproject.toml`):**
- `psycopg[binary]>=3.2` - PostgreSQL driver, used against Supabase-managed Postgres in production
- `pyjwt[crypto]>=2.9` - JWT validation of Supabase Auth access tokens (ES256 via JWKS, HS256 for dev fallback) — `backend/app/auth.py`
- `python-dotenv>=1.0` - Loads `.env` for local dev config (`backend/app/auth.py`, `backend/app/repository/db.py`)
- `pyyaml>=6.0` (dev extra) - Loads `content/*.yaml` question-bank content in `scripts/seed_dev.py`

**Critical (frontend, `frontend/pubspec.yaml`):**
- `http: ^1.2.0` - HTTP client talking to the FastAPI backend (`frontend/lib/api/api_client.dart`)
- `supabase_flutter: ^2.17.1` - Supabase Auth client SDK (email/password + Google OAuth, password recovery) — `frontend/lib/auth/auth_gateway.dart`, `frontend/lib/main.dart`
- `cupertino_icons: ^1.0.8` - iOS-style icon set

**Infrastructure:**
- SQLite (bundled, via SQLAlchemy) - Default/local database when `DATABASE_URL` is unset; also used for the test suite (`backend/certfly.db`, `backend/app/repository/db.py`)
- PostgreSQL (via Supabase) - Production database, connected through `DATABASE_URL`

## Configuration

**Backend environment (`backend/.env`, not committed; see `backend/.env.example`):**
- `DATABASE_URL` - Postgres connection string for Supabase; falls back to `sqlite:///./certfly.db` if unset
- `SUPABASE_URL` - Supabase project URL, used to fetch JWKS for JWT verification (`https://bmrucxfofwbcyyhgrzqt.supabase.co` is the real project referenced as the example default)
- `SUPABASE_JWT_SECRET` - Dev-only HS256 shared secret enabling locally-signed tokens (via `scripts/seed_dev.py`) without hitting real Supabase; must never be set in production

**Frontend environment (`frontend/lib/config/app_config.dart`):**
- Configured via Dart `--dart-define` / `--dart-define-from-file=dev.json` (generated by `scripts/seed_dev.py`)
- `apiBaseUrl` (default `http://localhost:8000`) - Backend API base URL
- `supabaseUrl` (default points to the real CertFly Supabase project) - Supabase project URL
- `supabaseAnonKey` (default is the Supabase "publishable key", safe to embed client-side) - Supabase anon/publishable key
- `devToken` - Dev-only pre-signed JWT to skip login (from `scripts/seed_dev.py`)
- `certificationId` - No "list certifications" endpoint in MVP scope, so the client must be told which certification to show; regenerated on each reseed, no hardcoded default

**Build:**
- `backend/pyproject.toml` - Python project/dependency/test config (setuptools + pytest `testpaths = ["tests"]`)
- `frontend/pubspec.yaml` - Flutter dependency and asset/font manifest (custom Nunito variable font, mascot/brand images, GCP/AWS/Azure provider logos)
- `frontend/analysis_options.yaml` - Dart static analysis config
